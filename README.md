# خلاصة المفيد | Kholasat Al Mofeed

منصة عربية RTL لاكتشاف وتنظيم الفيديوهات التعليمية من قنوات YouTube التي يضيفها المستخدم، مع مكتبة شخصية ومساعد Gemini.

> **مهم قبل النشر:** هذه نسخة تشغيلية أولى (Foundation / MVP متكامل للوظائف الأساسية)، وليست ادعاءً بأن كل بند في وثيقة المتطلبات الطويلة قد اكتمل. بعض الوحدات المتقدمة موضحة في قسم «ما لم يكتمل بعد». لن تعمل خدمات YouTube وGemini دون مفاتيح صحيحة، ولن يعمل التطبيق دون PostgreSQL.

## المتطلبات

- Node.js 20 أو أحدث (يفضل Node 22).
- npm.
- PostgreSQL.
- مفتاح YouTube Data API v3 لتفعيل البحث عن القنوات ومزامنة الفيديوهات.
- مفتاح Gemini API لتفعيل جيمناوي والتلخيص.

## التشغيل على Replit

1. أنشئ Repl جديدًا من نوع **Node.js**.
2. ارفع ملف ZIP إلى ملفات Replit. من Shell نفّذ `unzip -o kholasat-al-mofeed-replit.zip -d .` حتى تصبح ملفات `package.json` و`.replit` ومجلدا `server` و`client` مباشرة في جذر المشروع.
3. أنشئ قاعدة PostgreSQL من تبويب Database في Replit، ثم أضف رابط الاتصال إلى Secrets باسم `DATABASE_URL`.
4. افتح **Tools → Secrets** وأضف المتغيرات التالية:

| Secret | مطلوب؟ | القيمة |
|---|---:|---|
| `DATABASE_URL` | نعم | رابط PostgreSQL الذي يوفره Replit |
| `SESSION_SECRET` | نعم للنشر | قيمة عشوائية طويلة، 32 حرفًا أو أكثر |
| `ADMIN_PASSWORD` | نعم للوحة المالك | كلمة مرور إدارة قوية وفريدة |
| `YOUTUBE_API_KEY` | لتفعيل YouTube | مفتاح YouTube Data API v3 |
| `GEMINI_API_KEY` | لتفعيل جيمناوي | مفتاح Gemini API من Google AI Studio أو المشروع المعتمد |
| `YOUTUBE_DAILY_QUOTA` | اختياري | الحصة اليومية المخصصة لمشروع Google Cloud، الافتراضي 10000 وحدة |
| `GEMINI_MODEL_OVERRIDE` | اختياري | اسم موديل مستقر تريد تفضيله، بعد ظهوره ضمن الموديلات المدعومة |
| `GEMINI_FALLBACK_MODEL` | اختياري | موديل احتياطي، اختياري؛ إذا تُرك فارغًا يختار الخادم موديل Flash آخر متاحًا بعد الموديل الأساسي |
| `CHANNEL_SYNC_CRON` | اختياري | الافتراضي `0 */3 * * *` أي كل 3 ساعات |
| `PORT` | اختياري | الافتراضي 3001 |

لإنشاء `SESSION_SECRET` محليًا يمكنك استخدام:

```bash
openssl rand -hex 32
```

5. من Shell شغّل:

```bash
npm install
npm run dev
```

6. للنشر:

```bash
npm run build
npm start
```

ملف `.replit` مضبوط على تشغيل التطوير، ويحتوي على أمر بناء وتشغيل النشر. راجع إعدادات Deployment في Replit واختر بيئة تشغيل مناسبة للمهام المجدولة. **لا تعتمد على Autoscale أو إيقاف التطبيق عند الخمول لتشغيل Cron داخلي بصورة مضمونة**؛ إذا كانت الاستضافة توقف العملية، استخدم تشغيلًا دائمًا أو Scheduled Deployment / Cron خارجيًا يستدعي مهمة المزامنة الآمنة.

## التشغيل محليًا

1. انسخ `.env.example` إلى `.env`.
2. ضع رابط PostgreSQL والمفاتيح في `.env`.
3. نفذ `npm install` ثم `npm run dev`.
4. واجهة Vite تعمل افتراضيًا على `http://localhost:5173`، وخادم API على `http://localhost:3001`.
5. في أول تشغيل ينشئ الخادم الجداول والفهارس والمجالات الأساسية تلقائيًا من `server/schema.sql`.

## الخدمات الخارجية

### YouTube

- يستخدم الخادم YouTube Data API v3 للبحث عن القنوات وجلب بياناتها وقائمة Uploads ومعلومات الفيديو.
- تتم إضافة قناة بعد أن يختار المستخدم نتيجة البحث، لمنع إضافة قناة غير مقصودة بسبب تشابه الأسماء.
- تتم مزامنة أحدث 25 فيديو لكل قناة في كل دورة مزامنة.
- المزامنة المجدولة افتراضيًا كل 3 ساعات، وتعمل داخل عملية الخادم. يلزم تشغيل خادمي دائم أو مجدول خارجي موثوق لضمان تنفيذها.
- سجل الحصة داخلي وتقديري حسب تكلفة عمليات API الشائعة؛ لا يمثل قراءة مباشرة للحصة الفعلية من Google Cloud.
- لا توجد آلية تدوير مفاتيح للتحايل على الحصة.

### Gemini

- مفتاح Gemini يُقرأ على الخادم فقط ولا يصل إلى المتصفح.
- يطلب الخادم قائمة الموديلات ويختار موديل Flash مستقرًا يدعم `generateContent`، مع إمكانية تفضيل موديل مُتحقق منه ووجود موديل احتياطي.
- لا يتم إرسال رابط YouTube على أنه محتوى تمت مشاهدته. دون Transcript، تكون إجابة الفيديو مقيدة بالعنوان والوصف والبيانات المتاحة، وتظهر للمستخدم هذه المحدودية.
- يمكن للمستخدم لصق Transcript في صفحة الفيديو أو المحادثة للحصول على تحليل أعمق.

## الخصوصية والأمان

- دخول الاسم/الضيف ينتج UUID محليًا ويحفظه في `localStorage`، ثم تُخزن البيانات المرتبطة به في PostgreSQL. هذا **ليس حسابًا موثقًا**؛ مسح بيانات المتصفح أو تغيير الجهاز لا يوفر استعادة هوية آمنة.
- لوحة المالك محمية بكلمة مرور خادمية `ADMIN_PASSWORD` وجلسة JWT في Cookie من نوع HttpOnly. لا تستخدم اسم الضيف أو إخفاء رابط الإدارة كوسيلة حماية.
- في الإنتاج يجب ضبط `SESSION_SECRET` قويًا و`ADMIN_PASSWORD` قويًا، وعدم وضع مفاتيح API في كود الواجهة.
- يجب ضبط سياسة الخصوصية وشروط الاستخدام قبل استقبال مستخدمين حقيقيين.

## Routes الأساسية

- `/` الرئيسية.
- `/` تعرض شاشة الاستقبال عند عدم وجود مستخدم محلي، وتعرض الرئيسية بعد بدء الجلسة.
- `/explore` الاستكشاف والبحث داخل مكتبة المستخدم.
- `/categories` المجالات.
- `/channels` إدارة القنوات وإضافتها.
- `/video/:id` صفحة الفيديو ومشغل YouTube الرسمي.
- `/folders` و`/folders/:id` المجلدات.
- `/favorites` المفضلة.
- `/watch-later` المشاهدة لاحقًا.
- `/history` سجل المشاهدة والتقدم.
- `/summaries` الملخصات المحفوظة.
- `/ai` جيمناوي.
- `/paths` إنشاء ترتيب مبدئي للفيديوهات حسب المجال.
- `/settings` الإعدادات الفعلية الأساسية.
- `/profile` الملف الشخصي وتصدير/حذف بيانات المستخدم.
- `/admin` لوحة المالك المحمية.

## API وأهم الوظائف

- `GET /api/health` فحص تشغيل الخادم.
- `GET /api/ready` فحص اتصال قاعدة البيانات.
- `POST /api/users/ensure` إنشاء/تحديث المستخدم المحلي.
- `POST /api/channels/resolve` البحث عن قناة.
- `POST /api/channels` إضافة قناة مختارة.
- `POST /api/channels/:id/sync` تحديث قناة يدويًا.
- `GET /api/videos` جلب فيديوهات مكتبة المستخدم والبحث/التصفية.
- `POST /api/videos/:id/favorite` و`watch-later`.
- `POST /api/videos/:id/progress` حفظ التقدم.
- CRUD للمجلدات والعناصر.
- `GET/PUT /api/settings` إعدادات المستخدم.
- `GET/PATCH /api/notifications` مركز الإشعارات.
- `POST /api/ai/chat` محادثة Gemini محفوظة.
- `POST /api/ai/summarize/:videoId` إنشاء ملخص محفوظ.
- `GET /api/me/export` تصدير بيانات المستخدم بصيغة JSON.
- `DELETE /api/me/data` حذف بيانات المستخدم المرتبطة.
- `/api/admin/*` إحصائيات وخدمات محمية.

جميع طلبات المستخدم المحلية ترسل `x-user-id`. لا تعتبر هذه الآلية بديلًا عن مصادقة حقيقية إذا أضفت مزامنة بين الأجهزة أو بيانات حساسة.

## ما يعمل في هذه النسخة

- شاشة استقبال ودخول باسم أو كضيف.
- واجهة عربية RTL متجاوبة للهاتف والكمبيوتر، مع Dark/Light Mode وكثافة عرض البطاقات.
- صفحات رئيسية مستقلة عبر React Router.
- مجالات أولية محفوظة في PostgreSQL.
- البحث عن قناة بالاسم أو الرابط أو @Handle أو Channel ID.
- إضافة القنوات وإزالتها وتغيير مجالها ومزامنتها يدويًا.
- مزامنة مجدولة من الخادم كل 3 ساعات عند استمرار تشغيل العملية.
- عرض فيديوهات قنوات المستخدم فقط، مع بحث وفلاتر مجموعات.
- مشغل YouTube IFrame الرسمي، واستكمال موضع المشاهدة عند توافر أحداث المشغل.
- مفضلة، مشاهدة لاحقًا، مجلدات، إشعارات.
- Gemini chat، Transcript اختياري، ملخصات محفوظة ومحادثة حديثة محفوظة.
- إعدادات أساسية مرتبطة بالسلوك الفعلي.
- لوحة مالك محمية، إحصائيات، فحص حالة الخدمات، وسجل استخدام API.
- تصدير بيانات المستخدم وحذفها.
- App shell / manifest / Service Worker للأصول الثابتة فقط؛ لا يخزن API أو بيانات المستخدم في Cache دون اتصال.

## ما لم يكتمل بعد من المواصفات الموسعة

هذه العناصر ليست مفعّلة بالكامل بعد، ولا يجب تسويقها على أنها جاهزة:

- نظام حسابات موثق ومزامنة آمنة بين أجهزة متعددة، وصلاحيات فرق/مستخدمين.
- جميع المجالات الفرعية الستين والقواعد الذكية التفصيلية لتصنيف كل فيديو.
- تجميع فيديوهات دروس أونلاين تلقائيًا إلى كل التقنيات المطلوبة بمراجعة/تصنيف عالي الدقة.
- تقييم فائدة متعدد العوامل، كشف التكرار المتقدم، واقتراحات شخصية مدروسة.
- مسارات تعليمية محفوظة مع مراحل/اختبارات/Flashcards/تتبع أسبوعي ومراجعة متباعدة.
- توليد الأكواد والأدوات والروابط المستخرجة، ملاحظات بتوقيتات Transcript، مقارنة فيديوهين وتلخيص Playlist/قناة.
- لوحة إدارة كاملة لتحرير/إخفاء الفيديوهات والمجالات والقنوات العامة، وإدارة مفاتيح API من الواجهة.
- أرقام دقيقة لاستهلاك Gemini بالـ Tokens أو حصة Google الفعلية؛ لا تعرض الواجهات الحالية إلا البيانات المتاحة وسجلًا داخليًا.
- Telegram وWhatsApp Business وTikTok، Webhooks، PWA Offline للمحتوى، واختبارات E2E كاملة.
- نظام Analytics شامل لعدد الزوار النشطين ومعدل الاحتفاظ وساعات المشاهدة الدقيقة.
