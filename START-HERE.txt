خلاصة المفيد — النسخة المتكاملة 2.0.0
======================================

هذا هو مجلد سورس التطبيق كاملًا بعد دمج تعديل ربط YouTube API وGemini API داخل لوحة المالك.
لم تعد بحاجة إلى رفع ملف Patch منفصل أو استبدال ملفات يدويًا.

للتشغيل:
1) تحتاج Node.js 20 أو 22 وnpm.
2) افتح Terminal داخل مجلد المشروع وشغّل: npm install
3) انسخ .env.example إلى ملف اسمه .env.
4) غيّر ADMIN_PASSWORD وSESSION_SECRET وADMIN_SESSION_SECRET إلى قيم قوية وفريدة.
5) شغّل: npm run dev
6) افتح عنوان الواجهة الذي يظهر في الطرفية.
7) افتح /admin، وسجل دخول المالك، ثم أدخل مفاتيح YouTube وGemini واختبر الاتصال.

للتشغيل باستخدام Docker:
- بعد إنشاء .env، شغّل: docker compose up --build -d
- افتح http://localhost:3000

الأوامر:
npm run check    فحص ملفات الخادم وبنية المشروع
npm test         اختبارات بنية ثابتة
npm run build    بناء الواجهة
npm run verify   تنفيذ الفحوص والاختبارات والبناء

تنبيهات:
- لا ترفع .env أو مفاتيح API أو قاعدة البيانات إلى GitHub.
- لا تغيّر ADMIN_SESSION_SECRET بعد حفظ المفاتيح إلا بعد ترحيلها بشكل آمن.
- احتفظ بمجلد data على تخزين دائم.
- GitHub ليس استضافة تشغيل للتطبيق؛ يلزم Node.js أو Docker لتشغيل الخادم.
- راجع README_AR.md للتفاصيل وحدود الوظائف.
