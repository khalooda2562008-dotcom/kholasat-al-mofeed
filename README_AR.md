# خلاصة المفيد — النسخة المتكاملة 2.0.0

**خلاصة المفيد** منصة عربية لإدارة مكتبة الفيديوهات التعليمية التي تختارها من YouTube، وتنظيمها حسب المجالات والقنوات والمجلدات، ومتابعة تقدم المشاهدة، واستخدام مساعد Gemini باسم **جيمناوي**.

هذه الحزمة تحتوي على **السورس كود الكامل للمشروع** بعد دمج ملف إعدادات API داخل التطبيق. ليست Prompt، وليست Patch منفصلًا، وليست رابط موقع منشور.

## 1. المزايا الموجودة في الكود

### واجهة وتجربة الاستخدام
- واجهة عربية RTL بتصميم داكن ومتجاوب مع الهاتف والكمبيوتر.
- شاشة دخول سريعة بالاسم أو كضيف.
- الرئيسية، الاستكشاف، المجالات، القنوات، تفاصيل القناة، الفيديو، المشاريع، المكتبة، المجلدات، جيمناوي، الملخصات، الإعدادات، الملف الشخصي، ولوحة المالك.
- بطاقات فيديو تعرض الصورة والعنوان والقناة ومعلومات الفيديو.
- بحث داخل مكتبة المستخدم، وبحث منفصل في YouTube.
- مشغل YouTube الرسمي داخل صفحة الفيديو.
- حفظ تقدم المشاهدة واستكمال الفيديو من الموضع السابق.
- المفضلة، المشاهدة لاحقًا، سجل المشاهدة، وإنشاء مجلدات خاصة وإضافة الفيديوهات إليها.
- إعدادات للمظهر، كثافة العرض، الأداء، الإشعارات، وطريقة استخدام جيمناوي.
- تصدير بيانات المستخدم بصيغة JSON وحذف بياناته.

### القنوات والفيديوهات
- إضافة قناة برابطها أو `@handle` أو `Channel ID` أو اسمها.
- اختيار القناة الصحيحة عندما يرجع البحث أكثر من نتيجة.
- جلب بيانات القناة وأحدث الفيديوهات بواسطة YouTube Data API v3.
- إسناد القنوات إلى مجالات داخل مكتبتك.
- مزامنة مجدولة كل 3 ساعات طالما عملية الخادم تعمل.
- إنشاء إشعار داخلي عند وصول فيديوهات جديدة وفق إعدادات المستخدم.
- تصنيف مبدئي للفيديوهات التي تبدو كمشروعات بناءً على كلمات العنوان والوصف؛ هذا تصنيف آلي تقريبي وليس مراجعة بشرية.

### جيمناوي وGemini
- محادثة مع Gemini من خلال الخادم، وليس من المتصفح مباشرة.
- اكتشاف موديل يدعم `generateContent`، مع إمكانية تحديد موديل من متغيرات البيئة.
- سجل محادثة لكل ملف مستخدم محلي.
- إرسال بيانات الفيديو ونص التفريغ الذي تلصقه بنفسك إلى جيمناوي.
- لا يدّعي التطبيق أنه شاهد الفيديو لمجرد وجود رابط YouTube، ولا يستخرج التفريغ تلقائيًا في هذه النسخة.
- صفحة الملخصات تحفظ الملخصات التي أنشأها المستخدم داخل التطبيق.

### لوحة المالك وربط مفاتيح API — مدمجة داخل النسخة
- صفحة `/admin` محمية بكلمة مرور المالك وجلسة خادم في Cookie من نوع `HttpOnly`، ويوجد داخل صفحة الإعدادات اختصار مباشر إليها.
- إدخال مفتاح YouTube API ومفتاح Gemini API من الواجهة.
- حفظ المفاتيح داخل SQLite بعد تشفيرها بخوارزمية `AES-256-GCM`.
- إظهار حالة الربط وآخر أربعة أحرف فقط؛ لا يعيد الخادم المفتاح الكامل للمتصفح.
- اختبار اتصال YouTube واختبار طلب `generateContent` إلى Gemini.
- استبدال المفتاح أو حذف المفتاح المخزن.
- دعم متغيرات البيئة كخيار احتياطي عند عدم وجود مفتاح مخزن في قاعدة البيانات.
- لوحة المالك تعرض إحصاءات أساسية وسجل استهلاك API الداخلي وتقدير حصة YouTube.

> **مهم:** مفتاح YouTube وGemini لا يلزمان لفتح الواجهة أو تشغيل المكتبة المحلية، لكن يلزمان لإضافة قنوات من YouTube أو استخدام جيمناوي فعليًا.

## 3. متطلبات التشغيل

- Node.js إصدار 20 أو 22.
- npm.
- اتصال إنترنت عند تثبيت الحزم، وعند استخدام خدمات Google.
- مساحة تخزين دائمة لمجلد `data/` حتى لا تضيع قاعدة البيانات عند إعادة تشغيل بيئة الاستضافة.

**لا يعتمد المشروع على Replit أو Render تحديدًا.** يمكن تشغيله محليًا أو باستخدام Docker أو على أي خادم يدعم تشغيل Node.js. لكن لأن المشروع Full-Stack وفيه قاعدة بيانات ومفاتيح سرية، فلا يمكن نشر نسخة الخادم الفعلية على استضافة ملفات ثابتة فقط مثل GitHub Pages.

## 4. التشغيل المحلي

من داخل مجلد المشروع:

```bash
npm install
```

انسخ `.env.example` إلى ملف باسم `.env`، ثم ضع قيمًا حقيقية وفريدة بدل القيم الإرشادية:

```env
PORT=3000
NODE_ENV=development
DATABASE_FILE=./data/kholasat.sqlite
ADMIN_PASSWORD=ضع_كلمة_مرور_قوية_خاصة_بك
SESSION_SECRET=ضع_سرًا_عشوائيًا_طويلًا
ADMIN_SESSION_SECRET=ضع_سرًا_مختلفًا_وثابتًا
YOUTUBE_DAILY_QUOTA_BUDGET=10000
YOUTUBE_API_KEY=
GEMINI_API_KEY=
GEMINI_MODEL=
GEMINI_FALLBACK_MODEL=
```

لتوليد سر عشوائي آمن من Terminal:

```bash
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

استخدم ناتجًا مختلفًا لكل من `SESSION_SECRET` و`ADMIN_SESSION_SECRET`، ولا تغيّر `ADMIN_SESSION_SECRET` بعد حفظ مفاتيح API في قاعدة البيانات. تشفير المفاتيح مشتق من هذا السر؛ تغييره دون ترحيل المفاتيح يجعل النسخ المخزنة غير قابلة لفك التشفير.

تشغيل التطوير:

```bash
npm run dev
```

افتح عنوان Vite الظاهر في الطرفية، وغالبًا `http://localhost:5173`. الخادم يعمل افتراضيًا على `http://localhost:3000`.

## 5. ربط YouTube وGemini من داخل التطبيق

1. شغّل التطبيق وافتح `/admin`.
2. سجّل الدخول باستخدام `ADMIN_PASSWORD`.
3. افتح قسم **ربط مفاتيح API**.
4. أنشئ مفتاح YouTube من [Google Cloud Console](https://console.cloud.google.com/apis/library/youtube.googleapis.com)، مع تفعيل YouTube Data API v3.
5. أنشئ مفتاح Gemini من [Google AI Studio](https://aistudio.google.com/app/apikey).
6. الصق كل مفتاح في مكانه واضغط **حفظ المفتاح**.
7. اضغط **اختبار الاتصال** لكل خدمة على حدة.

يمكنك أيضًا وضع المفاتيح في `YOUTUBE_API_KEY` و`GEMINI_API_KEY` على الخادم بدل حفظها من اللوحة. الأولوية للمفتاح المحفوظ في قاعدة البيانات؛ إذا لم يوجد، يستخدم التطبيق متغير البيئة.

**لا تضع مفاتيح Google داخل ملفات React أو HTML، ولا ترسلها في مستودع GitHub، ولا تشارك ملف قاعدة البيانات أو ملف `.env`.** اختبار YouTube يستهلك وحدة حصة تقديرية، واختبار Gemini يرسل طلبًا فعليًا قد يُحتسب ضمن استخدام حسابك.

## 6. التشغيل باستخدام Docker

بعد إعداد `.env`:

```bash
docker compose up --build -d
```

افتح `http://localhost:3000`. تحفظ قاعدة البيانات في Docker volume باسم `kholasat_data` حتى لا تختفي عند إعادة إنشاء الحاوية. لإيقاف الخدمة:

```bash
docker compose down
```

لا تستخدم `docker compose down -v` إلا إذا كنت تقصد حذف وحدة البيانات وقاعدة البيانات نهائيًا.

## 7. أوامر الفحص والبناء

```bash
npm run check
npm test
npm run build
```

أو نفّذ الكل بهذا الأمر:

```bash
npm run verify
```

- `check`: يفحص Syntax الخادم، وجود الملفات الأساسية، ووجود وظائف دمج إعدادات API.
- `test`: ينفذ اختبارات بنية ثابتة باستخدام Node.js Test Runner؛ ليست اختبار E2E ولا اختبارًا حيًا لخدمات Google.
- `build`: يبني ملفات الواجهة باستخدام Vite.
- GitHub Actions يشغّل الفحوص والبناء على Node 20 و22 عند Push أو Pull Request.

## 9. البيانات والخصوصية والنسخ الاحتياطي

- تنشأ قاعدة البيانات تلقائيًا في `data/kholasat.sqlite`.
- مجلد `data/` يجب أن يبقى على قرص دائم في أي استضافة.
- خذ نسخة احتياطية من قاعدة البيانات ومن `ADMIN_SESSION_SECRET` معًا، واحفظهما في مكان آمن منفصل.
- ملفات SQLite مستثناة من Git بواسطة `.gitignore`.
- الدخول العادي في هذه النسخة هو ملف مستخدم محلي/ضيف بمعرّف UUID محفوظ في متصفح الجهاز؛ ليس نظام حسابات ببريد وكلمة مرور، ولا يزامن حساب المستخدم بين أجهزته.
- احذف بياناتك من صفحة الملف الشخصي أو صدّرها JSON قبل الحذف عند الحاجة.

## 10. ما الذي لا تدّعي هذه النسخة أنها تنفذه؟

هذه حزمة Full-Stack متكاملة للوظائف الموضحة أعلاه، لكنها ليست منصة إنتاج ضخمة مختبرة تحت ضغط آلاف المستخدمين. هذه الوظائف غير منفذة كمنتج مكتمل في النسخة الحالية: استخراج التفريغ الصوتي تلقائيًا من كل فيديو، تكامل Telegram/WhatsApp/TikTok، مزامنة حسابات المستخدم بين الأجهزة، اشتراكات ومدفوعات، مسارات تعليمية تكيفية واختبارات متقدمة، ولوحة تحليلات تعلم متقدمة. لا تعتبر اتصال Google ناجحًا قبل إدخال مفاتيحك واجتياز الاختبار الحي.

## 11. النشر العام

يلزم تشغيل الواجهة والخادم معًا على بيئة Node.js أو Docker، وضبط `NODE_ENV=production` و`ADMIN_PASSWORD` و`ADMIN_SESSION_SECRET`، وتأمين الاتصال عبر HTTPS، وربط `data/` بتخزين دائم. GitHub يحفظ السورس كود فقط ولا يشغّل Express أو قاعدة SQLite.

**الملف الحالي هو سورس التطبيق كاملًا بعد دمج صفحة مفاتيح API؛ وليس رابط موقع منشورًا.**
